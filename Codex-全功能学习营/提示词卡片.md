# 可复制提示词卡片

## 先理解，再动手

```text
先只读查看 <文件/目录>。解释 <问题> 的数据流和调用关系，引用具体文件；不要修改或运行网络命令。最后给出两个可选方案及取舍。
```

## 小范围实现

```text
实现 <目标>。范围只限 <文件/模块>；约束是 <约束>；验收为 <标准>。先说明计划，随后修改、运行 <验证命令>，最后汇总改动和未验证项。不要提交或推送。
```

## 修复故障

```text
复现步骤：<步骤>；期望：<期望>；实际：<实际>；日志：<日志>。请先定位并解释根因，再做最小修复，添加回归测试并报告验证结果。
```

## 只审查

```text
只审查 <范围>，不修改。按 P0/P1/P2 列出确定的问题：文件与位置、触发条件、影响和可行修复。不要把代码风格偏好当作缺陷。
```

## 安全边界

```text
这项任务不能：读取或输出密钥、访问生产环境、删除数据、提交、推送或发送外部消息。若完成需要其中任何一项，先停止并说明原因。
```

## 高质量追问

- “这个结论依据的是哪个文件或输出？”
- “请把改动缩小到解决该问题所必需的范围。”
- “这个测试是否会在旧实现上失败？”
- “哪些事情尚未验证？这会带来什么风险？”
- “给我一个不修改文件的替代方案。”
